=== PAGINA 25 ===
DO EXERCÍCIO ISOLADO PARA UM SISTEMA COM VÁRIAS REGRAS
O que é uma Base de Conhecimento (KB)?
KB é abreviação de Knowledge Base, ou Base de Conhecimento. Para esta aula, pense nela 
simplesmente como uma coleção organizada de fatos e regras que o sistema pode consultar ou 
usar para raciocinar.
KB = {R01, R02, R03, R04, R05, R06}
Se quisermos dizer matematicamente que todas as regras devem ser respeitadas 
simultaneamente, podemos pensar na conjunção:
KB = R01 ∧ R02 ∧ R03 ∧ R04 ∧ R05 ∧ R06
Na engenharia do sistema, mantenha as regras separadas. A conjunção global é uma forma matemática 
de pensar no conjunto; não é uma recomendação para manter uma expressão monolítica ilegível.

POR QUE DIVIDIR?
• fica mais fácil entender qual regra representa qual política;
• uma regra pode ser testada isoladamente;
